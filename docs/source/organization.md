# File Organization

GLHE is organized as three subpackages under the `GLHE` namespace:

- **CLAY** — gathers and processes data (`GLHE/CLAY/`)
- **LIME** — visualizes data via a Dash web dashboard (`GLHE/LIME/`)
- **CALCITE** — internal pub/sub message bus (`GLHE/CALCITE/`)

See [Architecture](architecture.md) for a detailed breakdown of each subpackage.
