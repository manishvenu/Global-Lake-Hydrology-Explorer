# Welcome to Global Lake Hydrology Explorer

**Global Lake Hydrology Explorer** (GLHE) is a Python library designed to visualize hydrology for lakes around the world and provide easy access to global data sources. It pulls data from the [HydroLakes database](https://www.hydrosheds.org/products/hydrolakes/) and offers a simple interface requiring no manual data preparation.

**Disclaimer**: This project is written by an undergraduate student with limited knowledge in hydrology and programming. It is not intended to be used for any serious research. Please use it at your own risk.
