## Project Description

The Global Lake Hydrology Explorer is a project I'm working on as an undergraduate student, and I'm still very much
figuring things out. The goal: create a tool that helps people who aren't hydrology experts make sense of complex
hydrology data.

This tool is about bridging that gap. Visualizing how water flows in and out of lakes using global datasets on
rainfall, evaporation, and runoff from all around the world. You select any lake in the world (above ~10 ha), and
this tool gives you a snapshot of its mass balance.

I'm doing this because I believe there is a growing gap between the complexity of data that hydrologists use and what
water resource managers need and can understand — two different languages. This tool tries to translate between them,
showing you step by step how the data turns into graphs and charts.
